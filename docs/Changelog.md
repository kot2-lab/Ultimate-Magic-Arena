## Ver.0.3.1

### Fixed
- タイトル画面で魔法陣（.magicCircle）がSTARTボタンのクリックを妨げる問題を修正
- 装飾要素に `pointer-events: none;` を適用し、UI操作の安定性を向上

## Ver.1.0.0

### Added
- 魔法作成・書庫管理、10段階CPU対戦、レベル成長、戦闘リザルト、ローカル保存を含むオフライン版を追加
- ファンタジーRPGの世界観に合わせたPC・タブレット・スマートフォン対応UIを追加
- BGM・効果音、動きの設定、セーブデータ書き出しを追加
- 追加決定事項を`Specification_Updates.md`と完全版`MASTER_GUIDE_v1.0.md`に記録
- GitHub Pages向けの自動公開ワークフローを追加（公開設定完了後に有効）

### Fixed
- STARTボタンを装飾要素が遮らないVer.0.3.1の修正を維持
- セーブデータ復元時にMP 0を誤って初期MPへ置き換える問題を修正
- 時限発動が敵の行動後に解決し、詠唱時にMPを二重消費しないよう修正
- 魔法工房で属性・形状を切り替えた際に特殊効果の選択が失われる問題を修正

## Ver.1.1.0

### Added
- 新しい冒険の開始時にユーザー名を設定し、6段階のチュートリアルでゲームの基本画面を順に案内
- 手引き画面からチュートリアルをいつでも再生できる機能
- 既存冒険のJSON・ブラウザー内バックアップを作成してから新しい冒険を始める確認
- セーブがない場合も「冒険をはじめる」の誤タップを防ぐ確認を追加

### Fixed
- セーブがないときに「冒険をつづける」を無効にし、保存済み進行状況を読み込んで再開するよう修正
- Ver.1.0形式の既存セーブはチュートリアル完了済みとして読み込み、初回案内で中断しないよう修正

### Documentation
- 追加仕様を`Specification_Updates.md`と完全版`MASTER_GUIDE_v1.1.md`に記録

## Ver.1.1.1

- ホーム、魔法書庫、チュートリアルの登録上限表示を20個に統一
- Ver.1.1.0以前のセーブデータと既存魔法をそのまま引き継ぎ可能

### Documentation
- 完全版ガイドを`MASTER_GUIDE_v1.1.1.md`として作成し、追加仕様を記録

## Ver.1.2.0

### Changed
- 戦闘画面に左右三レーンの位置図を追加し、敵・プレイヤー・狙い先を常時確認できるよう改善
- HP・MP表示、状態異常、戦闘ログと行動ボタンの視認性を向上

### Added

- レーン移動と決着にも短い演出を追加し、動きを抑える設定には引き続き対応

### Documentation
